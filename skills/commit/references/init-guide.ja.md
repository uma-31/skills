# 初期化ガイド

初期化では、設定ファイルを準備し、必要に応じてGitフックを登録する。手順は次のとおり。

## 初期化手順

### 1. `uv run scripts/commit.py init`を実行する

エラーなど、ユーザーからの明示的な指示以外の要因で初期化を開始している場合は、リポジトリにコミット規約がないことを伝えたうえで、初期化を進めてよいか確認し、承認を得てから下記のコマンドを実行する。そうでない場合は、直接実行する。

```bash
uv run scripts/commit.py init
```

コマンドの実行に失敗した場合、フォールバックせず、ユーザーに報告したうえで作業を中断すること。

### 2. 規約を設定する

ユーザーに、対話形式で調整するか直接編集するかを確認する。直接編集が選択された場合は、準備ができたと言われるまで待機する。対話形式が選択された場合は、[設定リファレンス](configuration.ja.md)を参照しながら1つずつユーザーに確認し、回答に応じて設定ファイルを編集する。

### 3. 初期化処理を再実行する

設定の調整が完了したら、`init`コマンドを改めて実行する。`hook.enabled`が有効な場合はここでフックが同期される。再実行しても副作用はない。

### 4. 設定ファイルの最小化を提案する

リポジトリ固有の設定だけが残るよう、設定ファイルからコメントとデフォルトと同じ値を削除することをユーザーに提案する。承認を得たら、下記のコマンドを実行する。

```bash
uv run scripts/commit.py minify
```
