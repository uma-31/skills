# 設定リファレンス

## 設定ファイル

ファイル名は`git-commit`で、先頭に`.`を付けて隠しファイルにもでき、拡張子は`.yaml`または`.yml`がサポートされている。
`git-commit.local.yaml`のように拡張子の前に`.local`を付けたファイルは、Git管理対象外とする設定の置き場として使える。
両方存在すればマージされ、競合するキーは`.local`が優先される。マージはマッピングであればキー単位で再帰的に行われるが、リストは要素単位ではなく丸ごと置き換わる。

設定ファイルは、カレントディレクトリから、現在のワークツリーのルートまで遡って探される。
リンクされたワークツリーで見つからなかった場合は、メインワークツリーの対応するディレクトリから同様に探される。

## 設定項目

省略したキーの値には、`assets/git-commit.default.yaml`のデフォルト値が使用される。
リストも、指定した場合はデフォルトの一覧が丸ごと置き換わる。

各キーの型・デフォルト値・基本的な意味は、`assets/git-commit.default.yaml`のコメントを参照する。

### 注意点

- `hook.enabled`の変更を反映するには`init`を再実行する必要がある
- 日本語など大文字・小文字の区別がない`language`では、`subject.case`を`any`にする。`lower`のままだと`Python`のような固有名詞で始まる件名が弾かれる
